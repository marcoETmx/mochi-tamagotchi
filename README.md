# Mochi — tu mascota kawaii

Juego Tamagotchi / Pou en 2D para el navegador móvil, hecho con [Phaser](https://phaser.io/). Cuida a Mochi: aliméntalo, juega, báñalo, cúralo y déjalo dormir para que no se ponga malito.

## Cómo jugar en local

```bash
npm install
npm run dev
```

Abre la URL de Vite en el teléfono (misma red) o en el navegador.

## Desplegar en Vercel

1. Entra a [vercel.com/new](https://vercel.com/new)
2. Importa este repositorio
3. Framework: **Vite** (se detecta solo)
4. Deploy

O con la CLI:

```bash
npx vercel
```
